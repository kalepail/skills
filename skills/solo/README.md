# Solo

Product-specific workflows for Solo and SoloTerm.

## Model-invoked

- **[fan-solo](./fan-solo/SKILL.md)**: Route broad or mixed Solo requests to the focused skills below.
- **[solo-set-up-projects](./solo-set-up-projects/SKILL.md)**: Configure projects, `solo.yml`, and shared commands.
- **[solo-customize-workspace](./solo-customize-workspace/SKILL.md)**: Configure workspaces, navigation, appearance, settings, and notifications.
- **[solo-run-processes](./solo-run-processes/SKILL.md)**: Control process lifecycle and restart behavior.
- **[solo-observe-services](./solo-observe-services/SKILL.md)**: Inspect status, output, ports, URLs, and readiness.
- **[solo-troubleshoot](./solo-troubleshoot/SKILL.md)**: Diagnose project, trust, shell, CLI, API, and runtime failures.
- **[solo-work-with-agents](./solo-work-with-agents/SKILL.md)**: Manage one bounded, owned Solo agent.
- **[solo-orchestrate-agents](./solo-orchestrate-agents/SKILL.md)**: Coordinate independent Solo worker lanes and verified integration.
- **[solo-track-todos](./solo-track-todos/SKILL.md)**: Maintain actionable work, blockers, locks, comments, and handoffs.
- **[solo-keep-scratchpads](./solo-keep-scratchpads/SKILL.md)**: Preserve plans, research, decisions, evidence, and project context.
- **[solo-close-out-work](./solo-close-out-work/SKILL.md)**: Promote durable conclusions and retire completed temporary state.
- **[solo-save-prompts](./solo-save-prompts/SKILL.md)**: Maintain reusable Solo prompt templates.
- **[solo-automate](./solo-automate/SKILL.md)**: Use Solo MCP, CLI, local HTTP API, hosted API, and deep links.
